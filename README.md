# 근육 총람 PWA — 설치·배포 안내 (완전 초보 기준)

## 0. 용어 세 가지만
- **PWA**: 인터넷 주소로 열리지만 휴대폰·PC에 **앱처럼 설치**되는 웹앱. 설치 후에는 인터넷이 없어도 열립니다.
- **호스팅**: 파일을 인터넷 주소에 올려 두는 것. 여기서는 무료인 **Cloudflare Pages**를 씁니다.
- **폴더 통째로 올린다**: 이 묶음 안의 파일 6개를 한 폴더에 둔 채로 그대로 올린다는 뜻입니다. 파일 이름을 바꾸면 작동하지 않습니다.

## 1. 폴더 안에 있어야 할 파일 (6개)
index.html / manifest.webmanifest / sw.js / icon-192.png / icon-512.png / icon-180.png / icon-maskable-512.png

## 2. 인터넷에 올리기 — Cloudflare Pages (약 5분)
1. 크롬에서 `https://dash.cloudflare.com` 에 접속해 로그인합니다. (계정이 없으면 무료 가입)
2. 왼쪽 메뉴에서 **Workers & Pages** 를 누릅니다.
3. **Create** → 위쪽 탭에서 **Pages** → **Upload assets** 를 누릅니다.
4. 프로젝트 이름을 영문으로 적습니다. 예: `muscle-atlas`
5. 파일 올리는 칸에 **이 폴더를 통째로 끌어다 놓습니다**(드래그).
6. **Deploy site** 를 누르고 1~2분 기다립니다.
7. `https://muscle-atlas.pages.dev` 같은 **주소**가 나옵니다. 이 주소가 앱 주소입니다.

## 3. 휴대폰 홈 화면에 설치
- **아이폰·아이패드**: 사파리로 그 주소를 엽니다 → 아래 공유 단추(네모+화살표) → **홈 화면에 추가** → 추가.
- **안드로이드**: 크롬으로 주소를 엽니다 → 오른쪽 위 점 세 개(⋮) → **앱 설치** 또는 **홈 화면에 추가**.
- 표지 화면에 **📲 이 기기에 앱으로 설치하기** 단추가 보이면 그것을 눌러도 됩니다.

## 4. PC에 설치
크롬으로 주소를 연 뒤 주소창 오른쪽의 설치 아이콘(⊕) 또는 ⋮ → **저장 및 공유 → 바로가기 만들기 → 창으로 열기 체크**.

## 5. 오프라인 동작
설치 후 한 번 열어 두면 내용이 기기에 저장되어, 이후에는 **비행기 모드에서도** 열립니다.

## 6. 내용을 고쳤을 때
새 index.html 을 받아 같은 방법으로 다시 올린 뒤, `sw.js` 안의 `const V = 'geunyuk-v6-20260924';` 에서 날짜 부분만 바꾸면 기기들이 새 내용을 내려받습니다. (이 작업은 제게 맡기시면 됩니다.)

## 7. 주의
- 이 주소는 **누구나 열 수 있는 공개 주소**입니다. 원내 전용으로 제한하려면 Cloudflare Access(무료 범위 있음)로 이메일 인증을 걸 수 있습니다. 필요하시면 설정 절차를 따로 만들어 드리겠습니다.
- 의료 내용은 표준 교과서 요약이며, 실제 진료 판단은 의장님 책임 하에 이루어집니다.
